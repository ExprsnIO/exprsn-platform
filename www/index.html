Under the hood

Ten formerly‑standalone services, now one deployable unit

CA, auth, Spark, Nexus, FileVault, Vault, Timeline, Prefetch, Moderator, and Live used to be ten separate microservices on ten separate ports. Exprsn collapses that into a single Express gateway with one Socket.IO server and one Postgres database — each module keeps its own schema, so isolation survives the consolidation.
