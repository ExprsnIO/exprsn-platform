Exprsn — UI mockups

Redesign explorations for four core surfaces, built on the platform's own design tokens (exprsn-unified.css). Each opens standalone; toggle light/dark with the button at the bottom-right of every page.

⌂

Timeline

Home/Global feed, composer, post cards with likes, comments, reposts and bookmarks, plus a trending rail.
✦

Spark

End-to-end encrypted messenger: conversation list, threaded bubbles, reactions, attachments and presence.
◎

Nexus

Group detail with cover, full tab bar, and a governance panel for proposals and member voting.
⚙

User settings

Profile, password, 2FA with backup codes, active sessions tied to CA tokens, and decentralized identity.

Mockups only — static HTML, no live data. Token vocabulary mirrors the real SPA so they can guide implementation in web/src.
