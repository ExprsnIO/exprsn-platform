## PM decisions for this slice (grounded in the FEAT-010 C/B)

- **Reason picker:** bind to the existing fixed `Report.reason` ENUM
  (`spam, harassment, hate_speech, violence, nsfw, misinformation, copyright,
  personal_info, other`) — a structured form per the "no JSON-only modals" rule; **no**
  new live `GET /reasons` endpoint this cycle.
- **Double-report UX:** a user cannot trivially double-report the same item — enforce a
  unique `(reportedBy, contentId)` guard (minor backend add on the existing `Report`
  table; if it lands as a column/constraint on the existing table, flag the ALTER path
  to dba — but the C/B scopes this as an optional unique guard, not a migration-heavy
  change). Confirm the exact rate-limit/confirmation copy with the PM at BUILD.
- **Slice:** **timeline-first** (the `web/src/features/timeline/PostCard.tsx` overflow
  surface already exists); **spark message reporting is a fast-follow**, filed separately
  if it doesn't fit the cycle.
