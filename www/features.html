Features

Eleven modules. One account. No context‑switching between apps.

Everything below runs behind the same login, the same design language, and the same privacy controls — because it's one platform, not ten products wearing the same logo.

⌂

Timeline

Home and global feeds, a composer, and post cards with likes, comments, reposts, and bookmarks. A trending rail highlights what's active across the network right now.

FeedRealtime
✦

Spark

End-to-end encrypted messenger with conversation lists, threaded bubbles, reactions, file attachments, and live presence — the keys never leave your device.

E2E encryptedRealtime
◎

Nexus

Groups and events with a full tab bar and a governance panel for member proposals and voting — community moderation that isn't just one admin's call.

GroupsGovernance
▶

Live

Real-time streaming with WebRTC signaling that's authenticated per event from the start — publish is in scope for launch, not a later add-on.

StreamingWebRTC
🛡

Vault

Secrets management as a dedicated module with its own Socket.IO namespace — application secrets get the same rigor as user data, not a stray .env file.

Secrets
🗂

FileVault

File storage with its own schema and access controls, so uploads, attachments, and media live in a purpose-built module instead of a generic bucket.

Storage
◆

Auth

OAuth2, OIDC, and SAML with multi-factor authentication. Sessions persist with revocable tokens, so signing out actually signs you out everywhere.

OIDCMFA
🔏

CA

A private certificate authority issues and rotates the tokens every other module trusts — the root of trust lives inside the platform, not a third party.

PKI
🔔

Moderator

Moderation queues and notifications with two dedicated realtime namespaces, so reports and alerts reach the right people the moment they happen.

ModerationRealtime
⚡

Prefetch

A caching layer that warms your feed ahead of time, backed by tiered Redis caches and background workers — the app feels instant, not eventually-consistent.

Performance
🌐

atproto

Support for the AT Protocol, so your identity and posts aren't locked to one server — Exprsn plays well with the wider federated social web.

Federation
