## Stage 4/6 — Token Gating & CA Integration

_Use/time-based + service tokens per Exprsn-CA token spec v1.1._ Selected: 6/7 · 14 pts

### Use-based token metering `use-metering` (M)

- **What:** one use decremented per inference call (CA atomic usesRemaining decrement; TOKEN_NO_USES_REMAINING → 402/403)
- **Gap today:** CA fully supports use tokens (services/ca/services/token.js:547); cortex only checks read/write perms
- **Ticket:** FEAT-TBD — file in `sprints/BACKLOG.md`

### Per-model/agent resource tokens `resource-tokens` (M)

- **What:** resource-scoped tokens (resourceValue /cortex/api/v1/models/<name>/*) gate which models/agents a bearer may use
- **Gap today:** CA matchesResource does wildcard/prefix; cortex passes only req.path
- **Ticket:** FEAT-TBD — file in `sprints/BACKLOG.md`

### Inbound service-token auth `inbound-service-hmac` (S)

- **What:** accept X-Service-ID/X-Service-Token HMAC so modules can call cortex over HTTP
- **Gap today:** cortex uses service tokens outbound only (jobs.js:67); shared authenticateService() is ready
- **Ticket:** FEAT-TBD — file in `sprints/BACKLOG.md`

### Group/org-scoped access `scope-groups` (M)

- **What:** v1.1 groupId/organizationId token scoping; SCOPE_INACTIVE + bulk revoke honored
- **Gap today:** CA v1.1 implements scoping end-to-end; cortex ignores scope fields
- **Ticket:** FEAT-TBD — file in `sprints/BACKLOG.md`

### Quota & budget accounting `quotas` (M)

- **What:** per-user/group/model budgets from PromptLog usage; enforce before dispatch
- **Gap today:** PromptLog records usage but nothing enforces limits
- **Depends on:** `use-metering`
- **Ticket:** FEAT-TBD — file in `sprints/BACKLOG.md`

### Cortex token admin UI `token-admin-ui` (S)

- **What:** issue/revoke cortex-scoped tokens in the SPA (bulk revoke by scope)
- **Gap today:** CA SPA modals exist for generic tokens; no cortex-specific issuance flow
- **Depends on:** `resource-tokens`
- **Ticket:** FEAT-TBD — file in `sprints/BACKLOG.md`
