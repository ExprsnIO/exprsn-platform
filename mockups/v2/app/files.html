Connect a drive

Open your Exprsn files in Finder, File Explorer or any WebDAV app.

  1. In Finder choose Go → Connect to Server (⌘K).
  2. Paste the server address and choose Connect.
  3. Sign in with your email and an access token as the password.
  1. In File Explorer, right-click This PC → Map network drive.
  2. Paste the server address and tick Connect using different credentials.
  1. In Files, choose Other Locations and enter davs://exprsn.io/filevault/webdav/.
Most desktop clients sign in with a username and password, which File Vault doesn’t accept yet. Until app passwords ship, use a WebDAV app that supports bearer tokens.
